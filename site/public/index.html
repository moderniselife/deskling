A little desk buddy for your AI agents.

Deskling is a 10-inch touchscreen that keeps an eye on every Claude Code and Cursor session you have running. It tells you when one needs you, lets you answer from across the room, and dozes off when you do.

Make one See the code

Open source, runs on a screen you can buy today, and talks only to a relay on your own Cloudflare account.

Tap a moment to see what Deskling does

Handle your agents from across the room.

No more checking terminals to see who's stuck. Every session on every machine shows up here, and the ones that need you come first.

Works with what you already use.

Install a plugin and your sessions show up. Start new ones from the screen with the agent, and the model, you like.

Claude Code

In the terminal, the desktop app and cloud sessions, on Mac and Windows. The whole conversation as it happens, with permissions, questions, messages and reminders.

Using Cowork or cloud sessions? Your relay's setup page has a personal plugin to upload in the Claude app, already filled in with your relay's details.

/plugin marketplace add moderniselife/deskling
/plugin install deskling@deskling
/plugin configure deskling@deskling

OpenCode

With any model OpenCode runs, local ones too through Ollama or LM Studio. The whole conversation, approvals, answers and messages, plus a small team of Deskling agents that plan, test, review and keep you posted while you're away.

The Deskling runner installs this for you, and lets you start OpenCode sessions from the screen with the model you pick.

mkdir -p ~/.config/opencode/plugins
curl -fsSL https://raw.githubusercontent.com/moderniselife/deskling/main/hooks/opencode/deskling.js \
  -o ~/.config/opencode/plugins/deskling.js

Gemini CLI, Cursor, Codex and more

The Deskling runner starts them from the screen and shows the whole session. Copilot, Goose, Qwen Code, Kimi and Kiro work too. In the Cursor editor, hooks show each chat and let you approve shell commands.

Everything else

Cron jobs, CI and other agents: if it can send a web request, it can ping Deskling.

deskling notify "Deploy finished"
deskling remind "Stretch" --in 20m

How it fits together.

Your agents and the screen meet at a tiny relay that you run yourself, for free, on Cloudflare. You don't need to open ports or own a server.

Your agents

Claude Code and Cursor on any computer, plus cloud sessions and scheduled jobs.

Your relay

A Cloudflare Worker on your own account. One click to deploy, and it should fit in the free plan.

Deskling

Stays connected over Wi-Fi, so taps go back in under a second. It updates itself.

The relay holds session names, short task summaries, reminders and the last few chat lines. Your code never passes through it, and nothing goes to a server run by anyone else.

Make your own.

An evening of setup and a weekend of printing. You plug in a cable once; everything after that happens over Wi-Fi.

  1. Get the screen

    Deskling runs on the Guition JC8012P4A1C: a 10.1-inch touchscreen board with an ESP32-P4 and Wi-Fi 6. Search for "JC8012P4A1C".

  2. Deploy your relay

    Pick a password, click deploy, and you get your own relay address with a setup page and a browser preview of Deskling.

  3. Install the firmware

    Plug the board into your computer and install from the browser, in Chrome or Edge. It picks the right build for your board.

    Install Deskling

  4. Say hi

    Pick your Wi-Fi on the screen, then open the address it shows and paste your relay details.

  5. Connect your agents

    Add the Claude Code plugin on each computer, and the OpenCode plugin if you use OpenCode. Run the Deskling runner to start sessions from the screen.

  6. Print its body

    Lilac bezel with ears, peach cheeks and a cream stand with toes. It prints without supports, and splits in two for 256 mm beds.

Questions.

Do I have to host anything?

Just the relay, and the Deploy button does it for you. It's a small Cloudflare Worker on your own account, and for one person it should fit in the free plan. Firmware updates come from this site.

What if I'm not at my desk?

Nothing changes. If you don't answer on the screen within 30 seconds, Claude asks on your computer as usual. You can change the wait in the plugin settings.

Can it be quiet?

Yes. There's a volume slider, and "Quiet at night" mutes everything between 10pm and 7am except the reminders you asked for.

Which agents does it work with?

Claude Code and OpenCode fully, with any model OpenCode can use, including local ones. The runner also starts Gemini CLI, Cursor, Codex, Copilot, Goose, Qwen Code, Kimi and Kiro from the screen. Anything else can send notifications, reminders and its status with one command.

Does it work with more than one computer?

That's the point. Install the plugin on each one, and every session shows up with the name of the machine it's on.

Can I try it before I have the board?

Yes. Deploy your relay and open its /app page: it's Deskling in your browser, with the same conversations, approvals and new sessions. Add it to your phone's home screen and it works there too.

I don't have a 3D printer.

It works fine without the case, propped up on a little stand. Any print service can make the parts from the STL files in the repo.
